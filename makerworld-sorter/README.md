# MakerWorld ランキング＆フィルタ（Chrome / Edge 拡張機能）

MakerWorld 全体のモデルを、キーワードなしで「いいね数」などの順に並べ替え、さまざまな条件で絞り込むための拡張機能です。

## インストール

1. このフォルダ（`makerworld-sorter`）をPCに保存します。ZIPの場合は展開します。
2. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開きます。
3. 右上（Edgeは左下）の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選びます。
5. MakerWorld（https://makerworld.com ）を開くと、右下に「★ ランキング」ボタンが出ます。

## 使い方

### ① データ取得
キーワードを空欄のまま「取得開始」を押すと、MakerWorld 全体から指定件数（最大1万件）を取得します。取得の順番は「いいね数」「ダウンロード数」「コレクション数」から選べます。キーワードを入れると、その検索結果だけを対象にできます。取得結果はブラウザに保存され、次回も使えます。

### ② 並べ替え
取得済みデータを次の基準で並べ替えます。いいね数、ダウンロード数、印刷数、コレクション数、コメント数、ブースト数、いいね率（いいね÷DL）、印刷率（印刷÷DL）、勢い（投稿からの1日あたりいいね・DL）、投稿日。

### ③ 絞り込み
いいね・DL・印刷・コレクションの下限、いいね率の下限、投稿期間（7日〜1年以内、指定日以降）、タイトルとタグに含む語・除外する語、作者名、ライセンス、独占モデル（のみ／除外）、スタッフピックのみ、印刷プロファイルありのみ、AI生成モデル除外、NSFW除外。

「CSV出力」で、絞り込み後の一覧を Excel で開ける CSV として保存できます。

## 注意

MakerWorld の公開されていない内部API（`/api/v1/search-service/select/design2`）を使っています。サイト側の仕様変更で動かなくなる可能性があります。また、サーバー側で取得できるのは並べ替え上位1万件までです。サーバーへの負担を避けるため、取得間隔は0.8秒以上を推奨します。
